# 전도서 31일 묵상 (모바일 웹)

**`qoheleth-31days.html` 한 파일**만 내려받아 휴대폰/PC 브라우저에서 열면 됩니다 (서버·인터넷 불필요, 유튜브 링크만 인터넷 필요).

- 기간: 2026년 10월 1일 ~ 10월 31일 (1일차 = 10/1)
- 본문: 개역한글(1961, 공개 도메인) 전도서 전체 221절을 31일로 나눔
- 오늘 / 주간 / 월간 / 진행 탭, 묵상 완료 체크는 브라우저(localStorage)에 저장
- 찬양 링크는 유튜브 검색을 조회수순으로 열어 줍니다.

수정: `data.js`(해석·적용·기도·곡), `verses.js`(본문) 편집 후 `python3 build.py` 로 단일 파일을 다시 만듭니다.
