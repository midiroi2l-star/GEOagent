# 전도서 31일 묵상 (모바일 웹)

정적 웹앱입니다. `index.html`을 열거나 아무 정적 호스팅에 올리면 동작합니다. 진행 기록은 브라우저 localStorage에 저장됩니다.

- 오늘 / 주간 / 월간 / 전체 진행 탭
- 매일: 본문 범위·요약, 해석, 적용, 기도, 찬송가 1곡, CCM 1곡
- 찬양 링크는 유튜브 검색을 조회수순(`sp=CAM%3D`)으로 열어 가장 조회수 높은 영상이 맨 위에 오도록 했습니다.
- 쉬운성경 본문은 저작권상 포함하지 않았고 본문 읽기 링크로 연결합니다.
- 내용 수정은 `data.js`에서 합니다.
